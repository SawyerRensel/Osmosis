# Bridge Types ^os-rlhd01

Every span is a negotiation between compression and tension. ^os-rlpar1

## Arch Bridges ^os-rlhd02

- Compression carries the load outward to the abutments ^os-rlbul1
- The Pont du Gard has carried its own weight since the first century ^os-rlbul2
- This bullet is untagged and must always stay visible

## Suspension Bridges ^os-rlhd03

- Main cables hang between the towers in a catenary curve ^os-rlbul3
- The deck hangs from vertical suspenders off those cables ^os-rlbul4

## Cable-Stayed Bridges ^os-rlhd04

- Cables run straight from tower to deck, with no main cable ^os-rlbul5
- Cheaper than suspension for medium spans ^os-rlbul6
