# Sidecar styles (T127)

This note starts with **no Osmosis data** in its properties, so with *Data
location* set to **Sidecar file** (the default) it is a sidecar-mode note.
Every mind map style written for it (fill, shape, border, branch line,
boundary, class, variant, theme, layout, background, reset) goes to the
`osmosis-styles` of its sidecar in `Osmosis/Data/`. This note's
properties must stay empty.
