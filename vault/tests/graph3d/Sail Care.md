# Sail Care

The near-tier fixture: open the 3D graph from this note and fly up close. Each line below should render as live Markdown over its plate, the full text wrapping where the plate cuts it off with an ellipsis.

## Callout

> [!warning] Before stowing
> Rinse salt off the sailcloth and let it dry fully, or mildew sets in.
