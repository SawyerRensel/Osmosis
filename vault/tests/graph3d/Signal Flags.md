# Signal Flags

The dense near-tier fixture: one heading with images, code blocks and tables packed under it. Open the 3D graph from this note and fly up close to "Flags to know". The panels should leave gaps between them where the edges show.

## Flags to know

- Alpha, diver down: ![[flag-alpha.svg]]
- Bravo, dangerous cargo: ![[flag-bravo.svg]]
- Charlie, yes: ![[flag-charlie.svg]]
- Delta, keep clear: ![[flag-delta.svg]]
- Echo, altering course to starboard: ![[flag-echo.svg]]
- Foxtrot, disabled: ![[flag-foxtrot.svg]]

```yaml
hoist:
  top: alpha
  bottom: bravo
```

```yaml
locker:
  shelf_1: [alpha, bravo, charlie]
  shelf_2: [delta, echo, foxtrot]
```

```text
Hoist one flag at a time from the starboard spreader.
```
