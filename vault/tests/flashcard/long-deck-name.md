# Long deck name

The deck this note declares has a deliberately long leaf name. A native
`<select>` sizes itself to its widest `<option>`, not to the option on show, so
before the fix this one deck stretched the stats scope bar past the width of a
phone screen and set the whole view scrolling sideways.

## Explicit

```osmosis
id: lngdeck01
What did masons build over a stone arch to hold its voussoirs until the
keystone was set?
***
Timber centering
```

## Line cards

- A voussoir is one of the wedge-shaped stones that make up an arch. ^os-lngdk01
- Scaffolding carries workers; centering carries the arch itself. ^os-lngdk02
